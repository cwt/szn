# Bug 333 — O(L^2) re-evaluation loop during Thai line rewrapping

### 333. O(L^2) re-evaluation loop during Thai line rewrapping
**File:** `src/grid.zig:531-555`
**Severity:** MEDIUM
**Status:** ✅ FIXED

During Thai line reflow in `src/grid.zig`, searching `word_breaks` iterated linearly from index 0 on every character, causing $O(L^2)$ performance degradation on long lines.

### Root Cause
Forward linear scan over sorted `word_breaks` array for each character.

### Fix
Optimized `word_breaks` lookup to scan backward from the current index, finding valid boundaries in $O(1)$ expected time.
