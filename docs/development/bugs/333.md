# Bug 333 — O(L^2) re-evaluation loop during Thai line rewrapping

### 333. O(L^2) re-evaluation loop during Thai line rewrapping
**File:** `src/grid.zig:521-522`
**Severity:** MEDIUM
**Status:** OPEN

During grid reflow, when line-wrapping Thai text, the code scans the entire `word_breaks` slice for every physical line break boundary.

### Root Cause
$O(L^2)$ linear scanning over long logical line break arrays.

### Impact
Significant CPU rendering lag when resizing terminal windows containing long lines of Thai text.
