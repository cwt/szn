# Bug 532 — `evictOldestIfFull` underflows on `max_buffers == 0`

### 532. Unguarded eviction when the capacity is zero
**Severity:** LOW
**Status:** Open
**Files:** [`src/buffer.zig:30-36`](https://github.com/cwt/szn/blob/main/src/buffer.zig#L30-L36)

## Problem

```zig
fn evictOldestIfFull(self: *BufferList) void {
    if (self.items.items.len < self.max_buffers) return;
    const oldest = self.items.items[self.items.items.len - 1];
    ...
}
```

When `max_buffers == 0`, the early return is skipped for an empty list
(`0 < 0` is false), so the next line reads `items.items[-1]` and panics
(index out of bounds). `max_buffers` defaults to 50 and is not wired to any
option today, so this is unreachable in production, but the guard does not
express the intended invariant.

## Proposed Fix

```zig
if (self.max_buffers == 0 or self.items.items.len < self.max_buffers) return;
```

or treat `max_buffers == 0` as "evict everything on push".

Identified by static analysis; not reproduced at runtime.
