# Bug 315 — cmdMoveWindow orphans window and leaks memory on insert OOM rollback failure

### 315. cmdMoveWindow orphans window and leaks memory on insert OOM rollback failure
**File:** `src/cmd/cmd.zig:228-237`
**Severity:** HIGH
**Status:** OPEN

When `cmdMoveWindow` extracts a window via `session.windows.orderedRemove(src_idx)` and attempts `insert(..., dst_idx)`, if insertion fails due to OOM, the rollback attempt `session.windows.insert(arena_alloc, src_idx, w) catch {}` uses the same exhausted allocator and silently fails.

### Root Cause
Rollback allocation relies on an exhausted arena allocator and swallows failure, leaving the extracted window unreferenced in `session.windows`.

### Impact
Permanent memory and file descriptor leak of the window and its child panes/PTYs on allocation failure.
