# Bug 322 — Synchronous blocking write in server response dispatch halts main loop

### 322. Synchronous blocking write in server response dispatch halts main loop
**File:** `src/server/dispatch.zig:97-120`
**Severity:** HIGH
**Status:** ✅ FIXED

In `src/server/dispatch.zig`, `std.c.write` retried only on `.INTR`, treating non-blocking `.AGAIN` / `.WOULDBLOCK` errors as failures or blocking the event loop.

### Root Cause
Missing `.AGAIN` and `.WOULDBLOCK` errno handling in socket write loop.

### Fix
Added `err == .AGAIN` retry handling in `src/server/dispatch.zig` (on Darwin, `std.c.E` defines `.AGAIN` for `EAGAIN`/`EWOULDBLOCK`).

### Impact
Server freezes for all attached sessions if a command client stalls.
