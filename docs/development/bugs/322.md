# Bug 322 — Synchronous blocking write in server response dispatch halts main loop

### 322. Synchronous blocking write in server response dispatch halts main loop
**File:** `src/server/dispatch.zig:97-120`
**Severity:** HIGH
**Status:** OPEN

`sendResponse` transmits command responses using synchronous blocking `std.c.write`.

If a client process stalls or stops reading from the socket, the server's main thread blocks indefinitely.

### Root Cause
Command socket writes perform blocking I/O on the main event loop thread without non-blocking buffers or event loop registration.

### Impact
Server freezes for all attached sessions if a command client stalls.
