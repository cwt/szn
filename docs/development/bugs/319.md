# Bug 319 — Desynchronization between Window.panes array rotation and Layout tree DFS rotation

### 319. Desynchronization between Window.panes array rotation and Layout tree DFS rotation
**File:** `src/window.zig:327-331`
**Severity:** HIGH
**Status:** OPEN

`Window.rotatePanes()` performs a linear array shift (`panes[i] = panes[i+1]`), whereas `self.layout.rotatePanes()` rotates leaf nodes based on layout tree Depth-First Search (DFS) order.

For 3+ pane layouts with non-uniform splits, linear array rotation order diverges from layout tree DFS traversal order.

### Root Cause
Asymmetrical rotation algorithms between linear pane list storage and tree layout storage.

### Impact
Pane ordering and focus movement desynchronizes from visual on-screen layout geometry.
