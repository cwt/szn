# Bug 392 — Dead code inventory

### 392. Unused / unreachable / misleading
**Severity:** LOW
**Status:** ✅ FIXED (partial)

### Removed
- `CopyMode.getCellAt` (unused wrapper) — deleted.
- `CopyMode.search_active` write-only field and its three writes — deleted;
  the server's `search_pending` remains the single source of truth.
- `adjustSelectionForAutoScroll(delta)` ignored its parameter — signature
  simplified to no-arg with a doc comment; both server call sites updated.

### Kept deliberately
- `CmdArgs.exec`'s `inline for` dispatch looks like a no-op but implements the
  comptime-table mandate from bug #335; replacing it with a direct call would
  regress that decision. Documented here instead.
- `identify_term` payload stays for wire compatibility (removing the message
  type would renumber the protocol enum); noted as reserved surface.
