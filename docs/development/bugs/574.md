# Bug 574 — Unreadable config files and directories look like empty configs

### 574. `fread` returning `0` is treated as EOF regardless of `ferror` or `EISDIR`

**Severity:** LOW  
**Status:** ✅ RESOLVED — `loadConfigFile` now rejects directories and checks `ferror()` after the bounded read; `fopen` failures are logged.  
**Files:** [`src/server/server.zig:4245-4260`](https://github.com/cwt/szn/blob/main/src/server/server.zig#L4245-L4260)  
**Related:** [Bug #545](./545.md) (bounded read replaced `fseek`/`ftell`), [Bug #573](./573.md), [Bug Index](./index.md)

## Symptom

```zig
const f = fopen(resolved_path_z.ptr, "r") orelse return;   // :4245 — open failure also silent
...
while (true) {
    const n = fread(&buf, 1, buf.len, f);
    if (n == 0) break;                                     // :4256 — no ferror check
    ...
}
if (content.items.len == 0) return;                        // :4260 — empty == valid
```

`fopen("/some/dir", "r")` succeeds on glibc; the first `fread` returns `0` with `EISDIR`. Likewise a mid-file read error yields `n == 0`. Both paths are indistinguishable from a genuinely empty config, so the server starts with default options without any warning[^src-1].

## Cause

The #545 rewrite to a bounded streaming loop preserved the original `n == 0 → break` logic and added no `c.ferror(f)` or `fstat`/`S_ISDIR` check. There is no `ferror`, `fstat`, or `S_ISDIR` use anywhere in `server.zig`.

## Fix

Prefer `std.fs.cwd().readFileAlloc(allocator, path, MAX_CONFIG_FILE_SIZE)`, which reports `error.IsDir` and I/O failures directly. If staying with libc, check `c.ferror(f) != 0` after the loop and reject non-regular files via `fstat` before reading; also log a warning when `fopen` fails instead of returning silently.

## Verification status

Confirmed against live source: `fopen` on a directory succeeds and `fread` returned 0 with `EISDIR`, which was indistinguishable from an empty config. Added an `opendir` probe, a `ferror` check after the read loop, and a warning on `fopen` failure; the regression test passes `/tmp` and asserts `error.ReadFailed`. `zig build test` passes on 0.16.0 and 0.17.x (1135 tests).
