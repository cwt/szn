# Bug 326 — Substring flag matching and combined flag failure in mapCommandToAction

### 326. Substring flag matching and combined flag failure in mapCommandToAction
**File:** `src/key_binding.zig:485-488`
**Severity:** MEDIUM
**Status:** OPEN

`mapCommandToAction` uses `std.mem.indexOf` to look for `" -h"`. This matches occurrences inside string arguments (e.g. `-t target-h`) and fails to recognize combined flags like `-vh`.

### Root Cause
Substring searching across unparsed command strings instead of structured argument tokenization.

### Impact
Incorrect command dispatch when key bindings contain target parameters containing flag substrings.
