# Bug 466 — modifyOtherKeys extkeys truncates wire value despite no-truncate comment

### 466. @truncate on untrusted CSI param
**Severity:** MEDIUM
**Status:** Open
**Files:** [`src/input.zig`](../../../src/input.zig)

---

### Root Cause Analysis

In [`src/input.zig:784`](../../../src/input.zig#L784):

```zig
// never truncate wire data into it (bug #355).
self.screen.extkeys = @truncate(self.params[1]);
```

`CSI > 4;999999 u` stores the low byte and enables flags the sender never requested.

### Proposed Fix

Range-check (`if (params[1] <= maxInt(u8)) ... else ignore/0`) instead of truncating, consistent with #354/#355. Add a test with an oversized value.
