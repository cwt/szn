# Bug 422 — DECSET 1003 (any-motion) is aliased onto the 1000 (click) flag — ESC[?1000l also disables motion tracking; mode.mouse_utf8 is dead

### 422. DECSET 1003 (any-motion) is aliased onto the 1000 (click) flag — ESC[?1000l also disables motion tracking; mode.mouse_utf8 is dead
**Severity:** LOW
**Status:** 🔴 OPEN

`1003 => self.screen.mode.mouse_standard = enable` shares one boolean with 1000. Applications commonly set `?1000h ?1003h` and later `?1003l`/`?1000l` independently; with one flag, turning click tracking off also kills any-motion reporting (and vice versa), desyncing apps like htop-style mouse UIs. Adjacent: `mode.mouse_utf8` is never set or read anywhere (consistent with the AGENTS.md SGR-only mandate — the field should not exist).

**Fix:** add a distinct `mouse_any` mode bit (or turn mouse modes into a small bitmask); delete `mouse_utf8`.
