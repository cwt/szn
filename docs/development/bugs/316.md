# Bug 316 — Sixel image refcounts leaked on vertical screen shrink in Screen.resize

### 316. Sixel image refcounts leaked on vertical screen shrink in Screen.resize
**File:** `src/screen.zig:510-522`
**Severity:** HIGH
**Status:** OPEN

`Screen.resize` delegates height reductions to `Grid.setSizeCursor`, which pops and deinits discarded bottom grid lines.

However, `Screen.resize` does not decrement `Screen.sixel_refcounts` for cells present on those discarded lines.

### Root Cause
Grid height truncation lacks callback or notification to Screen's sixel registry to decrement image slot reference counts.

### Impact
Sixel image memory remains locked in the registry after terminal resizing shrinks the display area.
