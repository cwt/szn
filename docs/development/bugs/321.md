# Bug 321 — Uncapped loop in CSI 'Z' handler causes CPU exhaustion DoS

### 321. Uncapped loop in CSI 'Z' handler causes CPU exhaustion DoS
**File:** `src/input.zig:643-644`
**Severity:** HIGH
**Status:** OPEN

The handler for CSI `'Z'` (Cursor Backward Tabulation) executes a `while (i < n)` loop where `n` is parsed directly from parameter inputs without upper cap bounds.

### Root Cause
Uncapped parameter loop execution without upper bounds checking or early loop termination guards.

### Impact
Rogue or malformed output sending `\x1b[99999999Z` locks up the server event loop in a CPU exhaustion DoS spike.
