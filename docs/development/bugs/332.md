# Bug 332 — Recursive layout tree traversals risk stack overflow on deep split hierarchies

### 332. Recursive layout tree traversals risk stack overflow on deep split hierarchies
**File:** `src/layout.zig:151-164`
**Severity:** MEDIUM
**Status:** ✅ FIXED

`findLeafParent` used unbounded recursion over layout tree nodes.

### Root Cause
Unbounded recursive call stack.

### Fix
Added depth parameter `depth` to `findLeafParentDepth` capping recursion at `MAX_LAYOUT_DEPTH = 64`.
