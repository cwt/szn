# Bug 332 — Recursive layout tree traversals risk stack overflow on deep split hierarchies

### 332. Recursive layout tree traversals risk stack overflow on deep split hierarchies
**File:** `src/layout.zig:147`
**Severity:** MEDIUM
**Status:** OPEN

Layout tree operations (`findLeafParent`, `findSiblingOfNode`, `findNodeBounds`, `collectLeafNodes`, `extractFromNode`, `removeFromNode`) use recursive function calls.

### Root Cause
Recursive algorithm implementation on unbounded tree structures.

### Impact
Server stack overflow crash on deeply nested pane layout trees.
