# Bug 313 — Window title callback calls allocator.free on Session arena

### 313. Window title callback calls allocator.free on Session arena
**File:** `src/window.zig:467-469`
**Severity:** HIGH
**Status:** OPEN

In `windowTitleCallback`, `self.name` is updated by duplicating `title` into `self.allocator` followed by `self.allocator.free(self.name)`.

Because `self.allocator` is the session's arena allocator, calling `free` is a no-op. Each window title change leaks the previous title string inside the session arena.

### Root Cause
Calling `allocator.free` on an arena allocator without recycling memory or tracking title lifetime.

### Impact
Steady memory leak inside the session arena on every window title update (e.g. process renaming).
