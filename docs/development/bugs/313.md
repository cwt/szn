# Bug 313 — Window title callback calls allocator.free on Session arena

### 313. Window title callback calls allocator.free on Session arena
**File:** `src/window.zig:253-273, 472`
**Severity:** HIGH
**Status:** ✅ FIXED

In `windowTitleCallback`, `self.name` was updated by duplicating `title` into `self.allocator` followed by `self.allocator.free(self.name)`.

Because `self.allocator` is the session's arena allocator, calling `free` is a no-op. Each window title change leaked the previous title string inside the session arena.

### Root Cause
Calling `allocator.free` on an arena allocator without recycling memory or tracking title lifetime.

### Fix
Added an inline `name_buf: [256]u8` buffer and a `setName(self: *Window, new_name: []const u8)` method to `Window`. Window title updates copy into the inline `name_buf` array without allocating from or freeing the arena. Added a unit test in `src/window.zig`.
