# Bug 472 — Dispatch write loops slice with @intCast(n) without clamping to remaining

### 472. Unchecked write-count-to-slice-index
**Severity:** LOW
**Status:** Open
**Files:** [`src/server/dispatch.zig`](../../../src/server/dispatch.zig)

---

### Root Cause Analysis

In [`src/server/dispatch.zig:126,147`](../../../src/server/dispatch.zig#L126) (`n: isize > 0` from `std.c.write`):

```zig
hdr_remaining = hdr_remaining[@intCast(n)..];
...
body_remaining = body_remaining[@intCast(n)..];
```

POSIX guarantees `n <= len`, but there is no `@min(n, len)` guard — a platform short-count anomaly panics with slice OOB instead of `WriteFailed`.

### Proposed Fix

Clamp (`const w: usize = @min(@as(usize, @intCast(n)), remaining.len)`) before slicing, or explicitly error when `n > len`.
