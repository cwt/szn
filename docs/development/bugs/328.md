# Bug 328 — Format string truncation specifier slices UTF-8 codepoints

### 328. Format string truncation specifier slices UTF-8 codepoints
**File:** `src/format.zig:724-736`
**Severity:** MEDIUM
**Status:** OPEN

The status line format string truncation specifier `=n:var` truncates strings using raw byte slicing (`value[0..n]`) rather than decoding UTF-8 codepoint boundaries.

### Root Cause
Naive byte slicing on UTF-8 string data.

### Impact
Multi-byte UTF-8 characters in status line variable expansions are split mid-codepoint, causing screen corruption.
