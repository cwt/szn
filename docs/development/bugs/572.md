# Bug 572 — Blocking 30 ms spin for each `if-shell` directive

### 572. The non-blocking `if-shell` fix still waits synchronously on the config-load thread

**Severity:** MEDIUM (performance)  
**Status:** ⬜ OPEN  
**Files:** [`src/server/server.zig:4180-4215`](https://github.com/cwt/szn/blob/main/src/server/server.zig#L4180-L4215)  
**Related:** [Bug #557](./557.md) (replaced blocking `c.system()` with fork + async pending queue), [Bug Index](./index.md)

## Symptom

```zig
var attempt: usize = 0;
while (attempt < 30) : (attempt += 1) {
    const rc = c.waitpid(pid, &status, WNOHANG);
    if (rc == pid) { ... break; }
    if (rc < 0 and std.c.errno(rc) != .INTR) { ... break; }
    var req: c.timespec = .{ .sec = 0, .nsec = 1_000_000 };
    _ = c.nanosleep(&req, null);          // :4199 — blocks the single server thread
}
if (!reaped) {
    const owned_cmd = self.allocator.dupe(u8, i.command) catch { ... };
    self.pending_if_shells.append(self.allocator, .{ ... }) catch { ... };
}
```

A fast condition still consumes one scheduler round-trip, but any condition that needs more than one poll costs up to **30 ms of dead time** on the main loop. Ten `if-shell` lines can stall connected clients for ~300 ms during `source-file`[^src-1].

## Cause

Bug #557 correctly removed the unbounded `c.system()` deadlock by forking and adding `pending_if_shells`, but kept a short busy-wait so simple conditions complete synchronously. The wait is fixed-length regardless of how quickly the child exits, and the async queue already exists as the escape hatch.

## Fix

Call `waitpid(pid, &status, WNOHANG)` once. If it returns `0` (still running), push `{ pid, owned_cmd, start_ms, depth }` straight onto `self.pending_if_shells` and return; let `tickIfShells`/`reapZombies` finish it. Keep the immediate success path only for `rc == pid`.

## Verification status

Found by source-level validation of the audit report against live source. `zig build test` passes; no test measures config-load latency with multiple slow `if-shell` directives.
