# Bug 577 — Two test-only fd bugs

### 577. Double `close()` of test socketpair endpoints and a platform-wrong `O_NONBLOCK` literal

**Severity:** LOW  
**Status:** ⬜ OPEN  
**Files:** [`src/server/server.zig:4823-4827`](https://github.com/cwt/szn/blob/main/src/server/server.zig#L4823-L4827), [`:5638-5672`](https://github.com/cwt/szn/blob/main/src/server/server.zig#L5638-L5672), [`:6333-6347`](https://github.com/cwt/szn/blob/main/src/server/server.zig#L6333-L6347)  
**Related:** [Bug #68](./068.md), [Bug #411](./411.md), [Bug #530](./530.md), [Bug Index](./index.md)

## Symptom

1. **Double close.** In `multiple display clients attached simultaneously` (`:5638`), `defer server.deinit()` (`:5640`) is combined with `defer _ = std.c.close(server_a)` / `server_b` (`:5647`, `:5655`) even though both fds are appended to `server.client_fds` (`:5662`, `:5672`), which `Server.deinit` closes at `:377-379`. The `.redraw` diff-state test (`:6333-6347`) has the same pattern. LIFO ordering means the explicit closes run first, then `deinit` closes the same numbers again. Today the second close returns `EBADF` (tests are sequential), but it is a latent recycled-fd hazard and would break under parallel tests.

2. **Wrong `O_NONBLOCK` on Linux.** The mouse-SGR test at `:4823-4827` uses an unnamed inline constant:

   ```zig
   _ = c_fcntl(fd, 4, c_fcntl(fd, 3, @as(c_int, 0)) | 0x0004);
   ```

   `0x0004` is the macOS/BSD value; Linux x86_64/aarch64 uses `O_NONBLOCK = 0o4000` (`0x0800`). The test's "program enables mouse mode" PTY master therefore stays blocking on Linux. The other nine `O_NONBLOCK` declarations in this file use a correct `comptime switch` with a Linux `0o4000` branch — only this block is wrong[^src-1].

## Cause

Copy-pasted test scaffolding that predates the centralized `io.setNonBlocking` helper (`io.zig:66-71`). The report's quoted `const O_NONBLOCK: c_int = 0x0004;` declaration does not exist; the defect is the inline literal.

## Fix

- Replace explicit `defer close` with `errdefer close` *before* handing ownership to `server`, then let `Server.deinit()` close exclusively (matching the `handleClient detach` tests).
- Replace the inline `fcntl` block with `io.setNonBlocking(fd)` or a shared `compat` constant with a Linux branch.
