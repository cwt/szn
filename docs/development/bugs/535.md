# Bug 535 — duplicate `Window.removePane` / `Window.extractPane`

### 535. Duplicated pane-removal logic
**Severity:** LOW (code quality)
**Status:** Open
**Files:** [`src/window.zig:447-496`](https://github.com/cwt/szn/blob/main/src/window.zig#L447-L496)

## Problem

`removePane` and `extractPane` share the same lookup, swap-remove, layout
update and resize steps; only the active-pane selection differs. The
layout-level pair was already collapsed under bug #520, but the Window-level
pair remains.

## Proposed Fix

Fold both into one function taking a flag (or an enum) for whether the pane
is being destroyed versus extracted, so the shared body exists once.
