# Bug 324 — cmdRenameWindow leaks window name memory into session arena

### 324. cmdRenameWindow leaks window name memory into session arena
**File:** `src/cmd/cmd.zig:189-191`
**Severity:** MEDIUM
**Status:** ✅ FIXED

`cmdRenameWindow` allocated `window.name` into the session arena using `a.dupe(u8, args[1])` without deallocating or recycling previous name allocations.

### Root Cause
Session arena allocations for window titles could not be reclaimed individually.

### Fix
Updated `cmdRenameWindow` in `src/cmd/cmd.zig` to use `window.setName(args[1])`, copying into the inline `Window.name_buf` array without allocating from the session arena.
