# Bug 324 — cmdRenameWindow leaks window name memory into session arena

### 324. cmdRenameWindow leaks window name memory into session arena
**File:** `src/cmd/cmd.zig:189-191`
**Severity:** MEDIUM
**Status:** OPEN

`cmdRenameWindow` allocates `window.name` into the session arena using `a.dupe(u8, args[1])` without deallocating or recycling previous name allocations.

### Root Cause
Session arena allocations for window titles cannot be reclaimed individually.

### Impact
Memory leak in session arena on frequent window renames.
