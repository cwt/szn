# Bug 325 — Option set -u directive silently ignored

### 325. Option set -u directive silently ignored
**File:** `src/cfg.zig:183-207`
**Severity:** MEDIUM
**Status:** ✅ FIXED

In `src/cfg.zig`, when parsing `set -u <option>`, matching `'u'` executed `return` early, silently discarding the option directive.

### Root Cause
Early return on `-u` flag instead of parsing option and flagging unset mode.

### Fix
Added `unset` boolean flag to `SetOpt.flags`, set `flags.unset = true` on `'u'`, parsed option name/value, and invoked `options.unset(option)` in `applyDirectives`.
