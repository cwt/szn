# Bug 325 — Option set -u directive silently ignored in configuration parser

### 325. Option set -u directive silently ignored in configuration parser
**File:** `src/cfg.zig:188-189`
**Severity:** MEDIUM
**Status:** OPEN

In `parseSetOption`, encountering the `-u` flag triggers an immediate `return`, skipping option unsetting logic without returning an error.

### Root Cause
Unimplemented `-u` flag handler causes premature control flow return.

### Impact
`set -u` configuration directives fail silently.
