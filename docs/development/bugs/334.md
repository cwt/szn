# Bug 334 — Dropped keystroke on interrupted UTF-8 continuation sequence

### 334. Dropped keystroke on interrupted UTF-8 continuation sequence
**File:** `src/tty/tty_key.zig:173-176`
**Severity:** LOW
**Status:** ✅ FIXED

In `feedUtf8`, when an interrupting non-continuation byte arrived while waiting for UTF-8 continuation bytes, the function returned `null` without processing the interrupting byte.

### Root Cause
Returning `null` on interrupted UTF-8 sequence instead of re-feeding the byte into `InputReader.feed`.

### Fix
Changed `feedUtf8` to return `rd.feed(byte)` when `byte & 0xc0 != 0x80`, re-evaluating the interrupting byte.
