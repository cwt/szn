# Bug 334 — Dropped keystroke on interrupted UTF-8 continuation sequence

### 334. Dropped keystroke on interrupted UTF-8 continuation sequence
**File:** `src/tty/tty_key.zig:173-176`
**Severity:** LOW
**Status:** OPEN

In `feedUtf8`, if a multi-byte UTF-8 sequence receives a non-continuation byte (`byte & 0xc0 != 0x80`), the parser resets state to `.ground` and returns `null`.

### Root Cause
Discarding non-continuation input bytes on invalid sequence reset.

### Impact
Keystrokes typed rapidly after malformed UTF-8 bytes are dropped.
