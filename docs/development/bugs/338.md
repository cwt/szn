# Bug 338 — Redundant status line string duplication per render frame

### 338. Redundant status line string duplication per render frame
**File:** `src/server/server.zig:2840`
**Severity:** LOW
**Status:** ✅ FIXED

In `renderToDisplayClient`, when `use_cache` was true, the cached status line string was duplicated (`allocator.dupe`) solely to be freed by a trailing `defer` statement.

### Root Cause
Unnecessary heap duplication to satisfy uniform cleanup flow.

### Fix
Refactored status line rendering in `src/server/server.zig` to maintain a non-owning slice `status_line_slice` for `display.renderAll` while only freeing `status_line_new` when a new status line is generated.
