# Bug 338 — Redundant status line string duplication per render frame

### 338. Redundant status line string duplication per render frame
**File:** `src/server/server.zig:2840`
**Severity:** LOW
**Status:** OPEN

In `renderToDisplayClient`, when `use_cache` is true, the cached status line string is duplicated (`allocator.dupe`) solely to be freed by a trailing `defer` statement.

### Root Cause
Unnecessary heap duplication to satisfy uniform cleanup flow.

### Impact
Allocation and deallocation overhead on every render frame.
