# Bug 344 — `main()` returns `void` instead of `!void` (Zig 0.16 rule #1)

### 344. `main` signature non-compliant with Zig 0.16
**File:** `src/main.zig:173`
**Severity:** LOW
**Status:** ✅ FIXED

Zig 0.16 rule #1 states: *"`main` takes `init`"* and the canonical form is:

```zig
pub fn main(init: std.process.Init) !void {
```

The previous signature was:
```zig
pub fn main(init: std.process.Init) void {
```

**Fix:** Changed signature to `!void`. Error handling inside `mainInner` is unchanged — the `catch |err|` block still logs and exits with code 1 on error.
