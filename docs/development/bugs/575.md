# Bug 575 — Timeout arithmetic is derived from wall-clock time

### 575. `io.currentMillis()` calls `gettimeofday`, while `compat.monotonicNs()` is never used for timeouts

**Severity:** MEDIUM  
**Status:** ⬜ OPEN  
**Files:** [`src/io.zig:50`](https://github.com/cwt/szn/blob/main/src/io.zig#L50), [`:60-63`](https://github.com/cwt/szn/blob/main/src/io.zig#L60-L63), [`src/compat.zig:42-48`](https://github.com/cwt/szn/blob/main/src/compat.zig#L42-L48), [`src/server/server.zig:427-428`](https://github.com/cwt/szn/blob/main/src/server/server.zig#L427-L428)  
**Related:** [Bug #568](./568.md) (cell-size timer), [Bug #350](./350.md) (escape timeout), [Bug Index](./index.md)

## Symptom

```zig
// io.zig:50, 60-63
extern "c" fn gettimeofday(tv: *std.c.timeval, tz: ?*anyopaque) c_int;
pub fn currentMillis() i64 {
    var tv: std.c.timeval = undefined;
    _ = gettimeofday(&tv, null);
    return @as(i64, @intCast(tv.sec)) * 1000 + @divFloor(@as(i64, @intCast(tv.usec)), 1000);
}
```

`Server.currentMillis()` merely forwards to it (`server.zig:427-428`). Every deadline is therefore wall-clock based:

- `cell_size_pending_since` (`:1000`, `:3499`) and `cell_size_wait_ms`;
- `pending_if_shells` `IF_SHELL_TIMEOUT_MS` (`:518`);
- escape-sequence timeout (`:795`, `:814`);
- auto-rename / `tcgetpgrp` throttles (`:3562`, via `Window.last_*_check_ms`);
- main-loop cell-size wait and diagnostics (`main.zig:436`, `:740`, `:989`).

A backwards NTP step makes elapsed deltas negative, so a slow sixel pane can stay paused indefinitely and queued `if-shell` children are never timed out. A forward step expires messages and escape sequences immediately[^src-1][^src-2].

## Cause

`compat.monotonicNs()` (`compat.zig:44-48`) is a correct POSIX `CLOCK_MONOTONIC` shim but was added for cross-version support and never wired into `currentMillis`. Note that `src/clock.zig`'s `time(null)` is *not* the problem — it renders the on-screen clock, where wall time is correct.

## Fix

Reimplement `io.currentMillis()` on top of `compat.monotonicNs()` (divide nanoseconds by 1 000 000), preserving the `i64` milliseconds signature and return shape so no caller changes. Keep `clock.zig` on wall time for display purposes only.

## Verification status

Found while re-checking the audit report's monotonic-clock checklist item against live source; the report pointed at `clock.zig` instead of `io.zig`. `zig build test` passes; no test steps the clock.
