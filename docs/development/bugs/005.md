# Bug 5 — cmdKillPane leaks killed pane

Pane memory is reclaimed by the session arena — `killWindow()` calls `pane.deinit()` (cleans up internal resources like PTY, choose mode, screen) and the pane's backing memory is freed when the session's arena resets on `killSession()`.
**Status: ❌ FALSE POSITIVE** — `removePane()` → `layout.removePane()` → `deinitNode()` destroys the pane via the layout tree.
