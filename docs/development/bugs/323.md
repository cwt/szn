# Bug 323 — Dummy pane allocation wasted in cmdBreakPane

### 323. Dummy pane allocation wasted in cmdBreakPane
**File:** `src/cmd/cmd.zig:440-452`
**Severity:** MEDIUM
**Status:** ✅ FIXED

`cmdBreakPane` calls `session.newWindow` which allocates an initial dummy `Pane`. `cmdBreakPane` replaces `new_win.panes.items[0]` with the broken-out pane and invokes `old_pane.deinit()` to close PTY fds and free screen buffers.

### Root Cause
Dummy pane allocated by `newWindow` required explicit `deinit()` to clean up PTY/screen state before replacing with the broken-out pane.

### Fix
Added `old_pane.deinit()` in `cmdBreakPane` to release PTY/screen resources, leaving struct memory cleanup to session arena reset per `AGENTS.md`.
