# Bug 323 — Dummy pane allocation wasted in cmdBreakPane

### 323. Dummy pane allocation wasted in cmdBreakPane
**File:** `src/cmd/cmd.zig:451-459`
**Severity:** MEDIUM
**Status:** OPEN

`session.newWindow` allocates a default dummy pane into the session arena. `cmdBreakPane` calls `old_pane.deinit()` and replaces `panes.items[0]` with the broken-out pane.

Because `deinit()` does not release arena memory, the dummy pane's memory remains allocated.

### Root Cause
Creating default window panes when initializing windows intended for pane migration.

### Impact
Accumulated memory bloat in the session arena on every `break-pane` action.
