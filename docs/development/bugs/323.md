# Bug 323 — Dummy pane allocation wasted in cmdBreakPane

### 323. Dummy pane allocation wasted in cmdBreakPane
**File:** `src/cmd/cmd.zig:440-452`
**Severity:** MEDIUM
**Status:** ✅ FIXED

`cmdBreakPane` calls `session.newWindow` which allocates a default initial `Pane` struct via `allocator.create(Pane)`. `cmdBreakPane` then replaced `new_win.panes.items[0]` with the broken-out pane and called `old_pane.deinit()`, but failed to free the `old_pane` struct pointer via `server.allocator.destroy(old_pane)`.

### Root Cause
Missing `allocator.destroy(old_pane)` call after `old_pane.deinit()`.

### Fix
Added `server.allocator.destroy(old_pane)` to release the dummy pane struct memory.
