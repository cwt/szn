# Bug 559 — Lao `U+0ECE` missing from `zero_width_ranges`, unchecked `connectProbeUnix` path length, and unverified socket dir

### 559. Minor edge cases in `char_width.zig`, `server/socket.zig`, and `socket_path.zig`
**Severity:** LOW  
**Status:** ⬜ OPEN  
**Files:** [`src/char_width.zig:355`](https://github.com/cwt/szn/blob/main/src/char_width.zig#L355), [`src/server/socket.zig:59-63`](https://github.com/cwt/szn/blob/main/src/server/socket.zig#L59-L63), [`src/socket_path.zig:20-30`](https://github.com/cwt/szn/blob/main/src/socket_path.zig#L20-L30)

## Problem

1. **Lao Yamakkan (`U+0ECE`) omitted from `zero_width_ranges` (`src/char_width.zig:355`)**:
   `src/thai.zig:66` includes `0x0EC8...0x0ECE` as Lao tone/combining marks, but `zero_width_ranges` in `src/char_width.zig:355` defines `{ .start = 0x0EC8, .end = 0x0ECD, .width = 0 }`, omitting `0x0ECE` (Lao Yamakkan, Unicode `GC=Mn`). As a result, `charWidth(0x0ECE)` returns `1` instead of `0`, so `Screen.writeChar` writes it into its own cell rather than attaching it as a combining mark.

2. **Unchecked `addr.path` slice bounds in `connectProbeUnix` (`src/server/socket.zig:59-63`)**:
   Unlike `ServerSocket.bind` (`src/server/socket.zig:20`, which checks `if (path.len >= addr.path.len) return error.PathTooLong;`), `connectProbeUnix` computes `const plen = std.mem.len(path);` and executes `@memcpy(dest[0..plen], path[0..plen]);` without checking `if (plen >= addr.path.len) return false;`, which panics on an overlong `-S` socket path.

3. **`socket_path.resolve` does not verify directory existence (`src/socket_path.zig:20-30`)**:
   If `XDG_RUNTIME_DIR` or `TMPDIR` is set to a non-existent directory path, `socket_path.resolve` returns `{dir}/szn.sock` without checking `access(dir, F_OK)`, causing `bind()` to fail instead of falling back to `/tmp/szn.sock`.

## Proposed Fix

1. Extend `{ .start = 0x0EC8, .end = 0x0ECD, .width = 0 }` in `src/char_width.zig:355` to `.end = 0x0ECE`.
2. Add `if (plen >= addr.path.len) return false;` before `@memcpy` in `connectProbeUnix`.
3. Check directory existence in `socket_path.resolve` before selecting `XDG_RUNTIME_DIR` or `TMPDIR`.
