# Bug 420 — forceReflow feeds the main-screen cursor into the alt-grid reflow and discards the clamped result — alt_cursor never clamped after resize

### 420. forceReflow feeds the main-screen cursor into the alt-grid reflow and discards the clamped result — alt_cursor never clamped after resize
**Severity:** LOW
**Status:** 🔴 OPEN

```zig
var alt_cx = self.cursor.x;   // should be alt_cursor.x
var alt_cy = self.cursor.y;
try g.forceReflowCursor(self.cursor.x, self.cursor.y, &alt_cx, &alt_cy);
```

The alt-screen reflow receives the *main* cursor as its reference point and the output parameters `alt_cx/alt_cy` are never written back to `self.alt_cursor`/`alt_saved_cursor`. After a resize with content on the alt screen, the wrong line is treated as the cursor line during reflow, and the stored alt cursor can remain beyond the reflowed geometry (visible when leaving alt screen). `resize` (:531-534) does both halves correctly for the main screen.

**Fix:** pass `alt_cursor.x/y` in and assign the clamped outputs back (mirroring :531-534).
