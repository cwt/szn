### Root Cause Analysis

In [`src/mode_copy.zig:304-307,313-316`](https://github.com/cwt/szn/blob/main/src/mode_copy.zig#L304):

```zig
extra = @as(u32, @intCast(-y_i64)); // traps for INT64_MIN
return getCellAtOffset(..., scroll_offset + extra); // wrapping +
```

Inputs are `±history` today, but there is no `+|`/saturate or empty early-return.

### Proposed Fix

Saturate the negation/addition and return empty (null cell) on overflow instead of wrapping.
