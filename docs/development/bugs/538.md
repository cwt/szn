# Bug 538 — client error reporting uses `std.debug.print`

### 538. Inconsistent logging in client I/O
**Severity:** LOW (code quality)
**Status:** Open
**Files:** [`src/client/client.zig:15`](https://github.com/cwt/szn/blob/main/src/client/client.zig#L15), [`src/client/client.zig:29`](https://github.com/cwt/szn/blob/main/src/client/client.zig#L29)

## Problem

```zig
std.debug.print("fdWrite failed with errno: {any}\n", .{err});
...
std.debug.print("fdRead failed with errno: {any}\n", .{err});
```

These are unbuffered, unstructured writes on error paths, unlike the
`std.log.*` calls used elsewhere. They also bypass the configured log
function.

## Proposed Fix

Replace with `std.log.warn`/`std.log.err` (or remove the diagnostic entirely,
since the error is already propagated).
