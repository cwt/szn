# Bug 374 — Detach notification dropped on EAGAIN

### 374. One of two remaining raw-write paths on non-blocking fds
**File:** `src/server/server.zig:1009-1017`
(also `sendRequestCellSize` at server.zig:2464-2470)
**Severity:** MEDIUM
**Status:** 🔴 OPEN

### Problem
```zig
while (remaining.len > 0) {
    const written_bytes = c.write(cfd, remaining.ptr, remaining.len);
    if (written_bytes < 0) { if (...== .INTR) continue; break; }   // EAGAIN → drop
```

Display sockets are flipped O_NONBLOCK by registerDisplayClient; when the peer
isn't reading, the 6-byte detach packet is truncated or lost entirely and the
client is never told to exit. Everything else routes through the POLLOUT queue
(`queueToClient`).

### Fix (proposed)
Use `queueToClient` for the detach reply (and audit sendRequestCellSize's raw
write — it drops EPIPE/EINTR too).
