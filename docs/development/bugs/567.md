# Bug 567 — `bench.sh` isolation, stale-socket cold-start, unequal pane-count, and `bench_report.py` matching bugs

### 567. `bench.sh` kills live sessions via global `pkill -9`, benchmarks stale-socket recovery, compares 5 vs 4 panes instead of 10, and `bench_report.py` misclassifies commands containing `"szn"`

**Severity:** MEDIUM (invalidated `szn` vs `tmux` comparison metrics + destructive side effects on live user sessions)  
**Status:** ✅ RESOLVED (rev `851:6c9f48cb2fdc`)  
**Files:**
- [`bench.sh`](https://github.com/cwt/szn/blob/main/bench.sh)
- [`tools/bench_report.py`](https://github.com/cwt/szn/blob/main/tools/bench_report.py#L69-L81)

**Related:** [Bug #566](./566.md), [Bug Index](./index.md)

## Symptom

Auditing [`bench.sh`](https://github.com/cwt/szn/blob/main/bench.sh) after investigating 122 orphaned `/opt/homebrew/bin/bash` shells ([Bug #566](./566.md)) revealed multiple measurement and isolation defects[^src-1][^src-2]:

| # | Defect | Impact |
|---|---|---|
| 1 | No socket isolation + global `pkill -9 szn` / `tmux kill-server` | Running `bench.sh` terminated all active `szn` and `tmux` sessions on the host, and `pgrep -x -n szn` could attach to the wrong PID. |
| 2 | `SIGKILL` leaves stale `szn.sock` before every cold-start run | Section 1 timed `szn`'s stale-socket `ECONNREFUSED` recovery path rather than a clean cold start, while `tmux kill-server` cleanly unlinked its socket. |
| 3 | Section 5 masked [Bug #566](./566.md) via `pkill -9 szn` | `szn new-session -d b && szn kill-session` never shut down the daemon, making create/destroy throughput apples-to-oranges against `tmux new -d -s b && tmux kill-session -t b`. |
| 4 | Vertical-only split loop (`split-window -v` × 9 with `\|\| break`) | In an 80×24 window, halving height hit minimum pane height early: `szn` created **5 panes/window (25 total)** while `tmux` created **4 panes/window (20 total)** — neither reached the labeled 10 / 50 panes. |
| 5 | Unnormalized `$SHELL` and nested env vars | Unlike [`tools/bench_throughput.sh`](https://github.com/cwt/szn/blob/main/tools/bench_throughput.sh#L88-L97), `bench.sh` inherited the user's interactive shell (e.g. `/opt/homebrew/bin/bash` + rc/starship) and failed if launched inside an existing `szn`/`tmux` session. |
| 6 | Substring matching in [`tools/bench_report.py`](https://github.com/cwt/szn/blob/main/tools/bench_report.py#L69-L81) | Checking `if "szn" in cmd:` before `elif "tmux" in cmd:` misattributed any `tmux` command whose socket name or path contained `"szn"` (e.g. `tmux -L szn-bench-...`), printing identical timings (`equal`) for both columns. |

## Cause

* [`bench.sh`](https://github.com/cwt/szn/blob/main/bench.sh) was written before [`tools/bench_throughput.sh`](https://github.com/cwt/szn/blob/main/tools/bench_throughput.sh) established isolated `/tmp` socket directories and `SHELL=/bin/sh` normalization[^src-1][^src-3].
* Repeatedly calling `split-window -v` on the active pane in an 80×24 window halves pane height (`24 → 12 → 6 → 3 → 1`) and terminates after 3–4 splits instead of 9, silently hidden by `2>/dev/null || break`[^src-1].
* [`tools/bench_report.py`](https://github.com/cwt/szn/blob/main/tools/bench_report.py#L69-L76) checked `"szn" in cmd` across the entire command string instead of inspecting the benchmark `name` or executable basename[^src-2].

## Fix

1. **Isolated sockets and non-destructive cleanup** ([`bench.sh`](https://github.com/cwt/szn/blob/main/bench.sh#L13-L63))[^src-1]:
   * Created a short `/tmp/szn-bench.XXXXXX/szn` directory (staying well within macOS's 104-byte `sun_path` limit), exported `XDG_RUNTIME_DIR="$SZN_SOCK_DIR"`, and isolated tmux with `tmux -L "tmux-bench-$$" -u`.
   * Renamed binary variables to `SZN_BIN` / `TMUX_CMD` and unset `SZN`, `SZN_PANE`, `TMUX`, and `TMUX_PANE` so `bench.sh` runs safely even from inside a live multiplexer session.
   * Normalized `export SHELL="/bin/sh"` (matching [`tools/bench_throughput.sh`](https://github.com/cwt/szn/blob/main/tools/bench_throughput.sh#L95)) and fixed the `"uzing"` typo.
   * Replaced global `pkill -9 szn` and `pgrep -x -n szn` with socket-scoped `lsof -t "$SZN_SOCK_DIR/szn.sock"` lookup (`find_szn_pid`), graceful `kill-session` teardown, targeted PID cleanup fallback, and `rm -f "$SZN_SOCK_DIR/szn.sock"` so every cold-start iteration benchmarks a fresh socketless startup.
2. **Exact 10-pane (2×5) and 50-pane geometry parity** ([`bench.sh`](https://github.com/cwt/szn/blob/main/bench.sh#L88-L111), [`bench.sh`](https://github.com/cwt/szn/blob/main/bench.sh#L155-L189))[^src-1]:
   * Added `split_to_10_panes_szn` and `split_to_10_panes_tmux`: 1 vertical split + 4 horizontal splits on the bottom row + `select-pane -U` + 4 horizontal splits on the top row = **exact 10 panes/window** (50 panes across 5 windows) with no swallowed split failures.
   * Updated the summary row label in [`tools/bench_report.py`](https://github.com/cwt/szn/blob/main/tools/bench_report.py#L249-L252) from `~50 panes` to `50 panes`[^src-2].
3. **Executable-aware result classification** ([`tools/bench_report.py`](https://github.com/cwt/szn/blob/main/tools/bench_report.py#L69-L81))[^src-2]:
   * Classified hyperfine JSON entries by command executable basename (`os.path.basename(cmd.split()[0])`) and benchmark `name` prefix before falling back to substring checks, eliminating false `"szn"` hits on `tmux` commands.

## Verification

* **Syntax & pane-count parity check:** `bash -n bench.sh` passes, and isolated verification confirms both `szn list-windows` (`0: szn* (10 panes)`) and `tmux list-windows` (`0: tmux* (10 panes) [80x24]`) build an exact 10-pane 2×5 layout per window.
* **End-to-end `./bench.sh` run (with [Bug #566](./566.md) fixed, `Zig 0.17.1` `ReleaseFast`):**

|---|---:|---:|---|

* **Post-run process check:** **0 leftover** `zig-out/bin/szn` or `tmux-bench-*` processes after `./bench.sh` exits.
