# Bug 6 — cmdJoinPane leaks dummy pane

The dummy pane is explicitly deinitialized with `dummy_pane.deinit()` before the function returns. Panes are allocated from the session arena, so even if the dummy somehow escaped deinit, the arena reset would reclaim it. The source pane (`sp`) intentionally survives for the move to the destination window.
**Status: ❌ FALSE POSITIVE** — The dummy is placed in `src_win.layout.root.leaf`, which is destroyed by `killWindow()` → `layout.deinit()`. The extracted `src_pane` intentionally survives for the move to `dst_win`.
