# Bug 534 — `Term` is test-only dead code

### 534. `Term` has no production caller
**Severity:** LOW (code quality)
**Status:** Open
**Files:** [`src/tty/tty.zig`](https://github.com/cwt/szn/blob/main/src/tty/tty.zig)

## Problem

`Term` (and its associated helpers) is exercised only by tests. Production
rendering goes through `Display`/`Screen`, so the type adds maintenance surface
and a second, drifted view of terminal behaviour without being shipped.

## Proposed Fix

Remove `Term` and its tests, or move it into a test-only module so it cannot
drift from the production renderer.

Identified by static analysis (prior audit L1, partial).
