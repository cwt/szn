# Bug 381 — `g` doesn't go to the top of history

### 381. Half-implemented pair
**File:** `src/mode_copy.zig:145-153` (cf. `placeCursorAtLogical`, :549)
**Severity:** MEDIUM
**Status:** 🔴 OPEN

### Problem
```zig
pub fn moveToTop(self: *CopyMode) void { self.cursor_y = 0; self.cursor_x = 0; }   // keeps scroll_offset
pub fn moveToBottom(self: *CopyMode, grid: ...) { ...; self.scroll_offset = 0; }
```

`G` jumps to the live bottom; `g` leaves whatever scroll offset was active, so
the viewport doesn't move to history top at all.

### Fix (proposed)
`moveToTop` should set `scroll_offset = historyLen()` and pin (matching the
placeCursorAtLogical remap), mirroring `G`.
