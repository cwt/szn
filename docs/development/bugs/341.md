# Bug 341 — `std.ArrayList(T).initCapacity()` is a pre-0.16 API removed in Zig 0.16

### 341. `initCapacity` — removed 0.15 API
**Files:** `src/cfg.zig:367`, `src/grid.zig:909,914`
**Severity:** HIGH
**Status:** 🔓 OPEN

Zig 0.16 removed the managed `ArrayList.initCapacity(allocator, N)` constructor. The 0.16 pattern is:

```zig
// WRONG (pre-0.16):
var result = try std.ArrayList(u8).initCapacity(allocator, s.len);

// RIGHT (0.16):
var result: std.ArrayList(u8) = .empty;
try result.ensureTotalCapacity(allocator, s.len);
```

**Affected call sites:**

| File | Line | Code |
|---|---|---|
| `src/cfg.zig` | 367 | `var result = try std.ArrayList(u8).initCapacity(allocator, s.len);` |
| `src/grid.zig` | 909 | `var vis_list = try std.ArrayList(GridLine).initCapacity(allocator, height);` |
| `src/grid.zig` | 914 | `var hist_list = try std.ArrayList(GridLine).initCapacity(allocator, h_count);` |

**Fix:** Replace each with `= .empty` + `try list.ensureTotalCapacity(allocator, N)`. Also ensure corresponding `defer list.deinit(allocator)` is present.
