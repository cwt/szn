# Bug 465 — SGR 38;2/48;2 wraps out-of-range RGB with mod 256 instead of ignoring

### 465. Inconsistent out-of-range policy between indexed and RGB SGR
**Severity:** LOW
**Status:** Open
**Files:** [`src/screen.zig`](../../../src/screen.zig)

---

### Root Cause Analysis

[`src/screen.zig:1454`](../../../src/screen.zig#L1454) (`38;5`): `if (idx <= 255)` else ignore — correct xterm (bug #354). [`src/screen.zig:1458-1462,1486-1490`](../../../src/screen.zig#L1458):

```zig
const r = params[i] % 256; // 300 -> 44, should clamp/ignore
```

### Proposed Fix

Clamp each of r/g/b to 255 or ignore the whole sequence when any component exceeds 255, matching xterm and the `38;5` arm. Cover fg and bg arms together.
