# Bug 335 — Command table execution uses function pointer dispatch violating AGENTS.md

### 335. Command table execution uses function pointer dispatch violating AGENTS.md
**File:** `src/cmd/cmd.zig:1645-1650`
**Severity:** LOW
**Status:** ✅ FIXED

`CmdArgs.exec` called `self.entry.exec(server, self.args)` through a function pointer. `AGENTS.md` guidelines mandate comptime `inline for` loops for table dispatches.

### Root Cause
Function pointer call in `CmdArgs.exec`.

### Fix
Added `inline for (CMD_TABLE) |entry|` loop to dispatch command functions at compile time.

### Impact
Violation of project design guidelines.
