# Bug 335 — Command table execution uses function pointer dispatch violating AGENTS.md

### 335. Command table execution uses function pointer dispatch violating AGENTS.md
**File:** `src/cmd/cmd.zig:1654-1656`
**Severity:** LOW
**Status:** OPEN

`CmdEntry` relies on function pointer tables (`exec: *const fn(...)`) for command execution.

AGENTS.md mandates: *"Generate command tables, key binding tables, and option definitions at comptime. Use inline for for dispatch loops instead of function pointer tables."*

### Root Cause
Using runtime function pointer tables instead of comptime `inline for` dispatch loops.

### Impact
Violation of project design guidelines.
