# Bug 4 — Pane memory leak on Window.deinit

Pane memory is cleaned up through the layout tree — `Window.deinit()` calls `layout.deinit()` which calls `deinitNode()` that does `pane.deinit()` + `allocator.destroy(pane)` for each leaf node. The pane memory is properly freed.
**Status: ❌ FALSE POSITIVE** — `Layout.deinitNode()` calls `pane.deinit()` + `allocator.destroy(pane)` for leaf nodes. Panes are fully cleaned up via the layout tree.
