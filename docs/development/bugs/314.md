# Bug 314 — Memory leak when expanding pane border format strings during rendering

### 314. Memory leak when expanding pane border format strings during rendering
**File:** `src/server/server.zig:2824`
**Severity:** HIGH
**Status:** ✅ FIXED

In `renderToDisplayClient`, expanding `pane_border_fmt_str` allocated a new string assigned to `pb.pane.border_format_cached`.

When format generator parameters updated or when multiple display clients iterated, old format strings were overwritten without being freed.

### Root Cause
Missing deallocation of cached border format strings before assigning new expanded allocations.

### Fix
Added `if (pb.pane.border_format_cached) |old_exp| self.allocator.free(old_exp);` prior to re-assigning `border_format_cached` in `src/server/server.zig`.
