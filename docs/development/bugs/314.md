# Bug 314 — Memory leak when expanding pane border format strings during rendering

### 314. Memory leak when expanding pane border format strings during rendering
**File:** `src/server/server.zig:2824`
**Severity:** HIGH
**Status:** OPEN

In `renderToDisplayClient`, expanding `pane_border_fmt_str` allocates a new string assigned to `pb.pane.border_format_cached`.

When format generator parameters update or when multiple display clients iterate, old format strings are overwritten without being freed.

### Root Cause
Missing deallocation of cached border format strings before assigning new expanded allocations.

### Impact
Continuous memory leak during rendering when border format options change or under multi-client connections.
