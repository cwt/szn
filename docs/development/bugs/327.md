# Bug 327 — Copy mode single-line backward selection yank failure

### 327. Copy mode single-line backward selection yank failure
**File:** `src/mode_copy.zig:336-338`
**Severity:** MEDIUM
**Status:** OPEN

In `yankSelection`, when text is selected backward on a single line (`sy == ey`), `line_start` is set to `sx` (start_x) and `line_end` to `ex` (end_x).

Because `sx > ex`, the iteration loop `while (x <= line_end)` immediately terminates.

### Root Cause
Missing coordinate normalization (min/max swap) for single-line backward selections.

### Impact
Copying text by selecting backward on a single line yields empty string output.
