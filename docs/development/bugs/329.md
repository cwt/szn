# Bug 329 — Missing OSC discard transition on buffer overflow causes input injection

### 329. Missing OSC discard transition on buffer overflow causes input injection
**File:** `src/input.zig:337-339`
**Severity:** MEDIUM
**Status:** OPEN

When `osc_buf` exceeds capacity limit, `InputParser` executes `self.osc_buf.clearRetainingCapacity()` and transitions to `.ground` state immediately, without waiting for the String Terminator (ST/BEL).

### Root Cause
Missing transition to an `osc_discard` state to swallow the remainder of oversized OSC sequences.

### Impact
Un-discarded trailing bytes of large OSC control strings leak into the grid as literal text or control commands.
