## Resolution

### Unified

- `cmdHelp` vs `formatHelp` (`src/cmd/cmd.zig`): extracted shared
  `appendEntrySummary` / `appendEntryDetail` emitters; both paths now call
  the same code so the outputs cannot drift.
- Sixel slot searches (`src/screen.zig`): `isImageReferenced` and
  `findSixelImage` are now one-line wrappers over the single
  `findSixelImageSlot` scan.
- Render row resolution (`src/server/render.zig`): extracted shared
  `resolveRowCells` used by both the merge stage and the single-pane
  content path.
- Border arms (`src/server/render.zig`): extracted shared
  `paintBorderCell` (cross-merge rule + fg paint).
- Status width walk (`src/status.zig`): extracted shared `measureChunk`
  used by both `visibleLen` and `truncateVisible`.
- Layout split math: centralized in `layout.splitSizes` (fixed under bugs
  #467/#468, which also resolves this cluster's triplication item).
- `cfg.trimLeft`: replaced with stdlib (fixed under bug #476).
- Dead params removed: `clock.renderClock` no longer takes the ignored `sx`;
  `ChooseMode.handleKey` no longer takes the unused allocator (9 call sites
  updated); `cmdFindWindow` calls `std.ascii.indexOfIgnoreCase` directly
  (one-line wrapper deleted).

### Deliberately kept (documented in code)

- `scrollUpInRegion` / `scrollDownInRegion` mirrors: every line differs
  (loop direction, blank target, anchor delta, cursor guard) and these paths
  have a history of region bugs (#368/#369/#419) — explicit beats clever.
- Format conditional/compare/and-or bodies: arities and semantics genuinely
  differ; the shared primitives (`splitArgs`, `expandTemp`, `freeArgs`)
  already are the factored layer.
- `GridLine.dirty`: retained with a doc comment — it carries tested copy
  semantics through scroll/clone/compact, and a merge-stage skip needs
  scroll-aware mapping to be correct (future work, not removable safely).

Full suite (`zig build test`) passes.
