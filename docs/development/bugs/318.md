# Bug 318 — Layout split failure leaves pane internal dimensions un-restored

### 318. Layout split failure leaves pane internal dimensions un-restored
**File:** `src/layout.zig:125-135`
**Severity:** HIGH
**Status:** ✅ FIXED

In `src/layout.zig`, `pane.resizeTerminal(child_w1, child_h1)` was called before creating split nodes. If node creation failed, `pane` was left with resized terminal dimensions despite split failure.

### Root Cause
Missing rollback for `pane.resizeTerminal` on split node allocation failure.

### Fix
Captured original dimensions `old_w` and `old_h` and added `errdefer pane.resizeTerminal(old_w, old_h) catch {}`.
