# Bug 318 — Layout split failure leaves pane internal dimensions un-restored

### 318. Layout split failure leaves pane internal dimensions un-restored
**File:** `src/layout.zig:132-143`
**Severity:** HIGH
**Status:** OPEN

`Layout.splitPane` calls `pane.resizeTerminal(child_w1, child_h1)` before layout node memory is committed.

If subsequent node allocation fails, `errdefer` rolls back node creation, but original pane dimensions (`parent_w`, `parent_h`) are not restored to `pane`.

### Root Cause
Mutating pane state prior to fallible layout tree node allocations without unwinding pane dimensions on error.

### Impact
Pane grid dimensions desynchronize from layout tree bounds on allocation failure.
