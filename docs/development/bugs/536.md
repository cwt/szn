# Bug 536 — `layout.extractPane` is an alias

### 536. Redundant wrapper
**Severity:** LOW (code quality)
**Status:** Open
**Files:** [`src/layout.zig:369`](https://github.com/cwt/szn/blob/main/src/layout.zig#L369)

## Problem

```zig
pub fn extractPane(self: *Layout, pane: *Pane) void {
    self.removePane(pane);
}
```

There is no behavioural difference between the two. Callers can invoke
`removePane` directly.

## Proposed Fix

Remove `extractPane` and update its callers to `removePane`.
