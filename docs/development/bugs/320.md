# Bug 320 — State desync on cmdJoinPane layout node lookup failure

### 320. State desync on cmdJoinPane layout node lookup failure
**File:** `src/cmd/cmd.zig:421-422`
**Severity:** HIGH
**Status:** OPEN

In `cmdJoinPane`, the source pane `sp` is extracted from `src_win` and appended to `dst_win.panes`.

If `dst_win.layout.findLeafParent` subsequently returns `null`, the command immediately aborts with `.err` without rolling back the pane list modifications.

### Root Cause
Performing structural pane list modifications before validating layout tree node existence.

### Impact
Destination window contains `sp` in `panes` list without a matching layout node, causing rendering/resize failures.
