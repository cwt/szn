# Bug 471 — Loop.pollOnce returns address of stack temporary for empty poll

### 471. Dangling empty slice on the no-event path
**Severity:** LOW
**Status:** Open
**Files:** [`src/server/loop.zig`](../../../src/server/loop.zig)

---

### Root Cause Analysis

In [`src/server/loop.zig:91,105`](../../../src/server/loop.zig#L91):

```zig
if (self.fds.items.len == 0) return &[0]PollEvent{};
...
if (ready == 0) return &[0]PollEvent{};
```

Address of a stack temporary escapes. Length `0` makes it benign today, but any future `.ptr` use is a use-after-return.

### Proposed Fix

Return `self.event_buf.items` (cleared) or a static empty sentinel instead of a stack address.
