# Bug 434 — Region scroll paths skip shiftSixelAnchors, desyncing sixel image anchors

### 434. Region scroll paths skip shiftSixelAnchors, desyncing sixel image anchors
**Severity:** MEDIUM
**Status:** Open

The full-grid scroll operations call `shiftSixelAnchors(delta)` to keep sixel image `anchor_row` values in sync with content movement. The **region** scroll helpers do not:

```zig
// src/screen.zig:592-608 (scrollUpInRegion) and 610-626 (scrollDownInRegion)
// swap lines within [top, bottom] but never call shiftSixelAnchors(...)
```

Contrast with the non-region paths, which do shift anchors:

```zig
// src/screen.zig:373, 410, 640, 1196, 1204, 1238, 1246 — shiftSixelAnchors(...) on scroll
```

### Problem & Impact
- When content scrolls within a DECSTBM scroll region that contains sixel images, the images' `anchor_row` values are not adjusted, so they end up anchored to the wrong row relative to the text that scrolled.
- Visual corruption: sixel graphics detach from their surrounding text after a region scroll; mouse hit-testing on sixel (which uses `anchor_row`) points at the wrong location.

### Proposed Fix
Call `shiftSixelAnchors(delta_rows)` inside `scrollUpInRegion`/`scrollDownInRegion` for the lines actually moved (respecting the `alt_screen` tag so only the active screen's images shift, per bug #219), mirroring the full-grid scroll behavior.
