## Cause

Accumulated scaffolding from earlier parser/socket refactors. None of these items has runtime impact; they are maintenance surface only.

## Fix

Remove items 1–5. For item 2, change `btn_type` to `u2` via `@truncate(btn)` and drop the `else` arm. For item 3, remove the variant and tidy exhaustive `switch (ev)` sites. For item 4, prune the unused error variants or wire them to real failure paths.

## Verification status

Confirmed by direct source inspection: items 1, 2, 3, 5 and two of the three error variants were dead. `OutOfMemory` was *not* dead — `createListener` uses `try socket_path.resolve()` whose error set includes it — so it was kept. All removals compile cleanly with no behavioural change; `zig build test` passes on 0.16.0 and 0.17.x (1137 tests).
