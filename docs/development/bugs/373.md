# Bug 373 — EAGAIN treated as fatal on display client reads

### 373. Transient WouldBlock tears down healthy connections
**File:** `src/server/server.zig:2231-2237`; caller `run()` at 604-608
**Severity:** MEDIUM
**Status:** 🔴 OPEN

### Problem
```zig
const n = std.posix.read(fd, &buf) catch |err| {
    ...
    return error.ReadFailed;   // → removeClient(cfd)
```

`registerDisplayClient` flips the socket to non-blocking; on any spurious wake
or edge race the read returns `WouldBlock` and the whole DisplayClient is
destroyed instead of waiting for the next POLLIN.

### Fix (proposed)
Map `error.WouldBlock` to a benign zero-progress return in `handleClient`;
propagate only real errors as disconnects.
