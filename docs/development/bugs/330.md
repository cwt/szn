# Bug 330 — Input parser drops interrupting Escape (0x1B) control bytes

### 330. Input parser drops interrupting Escape (0x1B) control bytes
**File:** `src/input.zig:304, 315`
**Severity:** MEDIUM
**Status:** ✅ FIXED

In `advanceCsiParam` and `advanceCsiIntermediate`, receiving `0x1B` fell into `else => self.toGround()`, dropping to `.ground` without entering `.esc`.

### Root Cause
Missing `0x1B` branch in CSI state handlers.

### Fix
Added `0x1B => { self.toGround(); self.state = .esc; }` handlers in `advanceCsiParam` and `advanceCsiIntermediate`.


### Impact
Interrupted CSI control sequences swallow subsequent valid escape sequence prefix bytes.
