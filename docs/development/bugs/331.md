# Bug 331 — SIGWINCH configured with SA_RESTART delays client resize redraws

### 331. SIGWINCH configured with SA_RESTART delays client resize redraws
**File:** `src/main.zig:642-646`
**Severity:** MEDIUM
**Status:** OPEN

`SIGWINCH` signal handler configuration includes `SA_RESTART`.

When a SIGWINCH signal arrives while `poll()` is blocking, the kernel transparently restarts `poll()` instead of interrupting it with `EINTR`.

### Root Cause
Using `SA_RESTART` on signals intended to wake up event loops.

### Impact
Client display redraws on window resize are delayed until another event occurs.
