# Bug 331 — SIGWINCH configured with SA_RESTART delays client resize redraws

### 331. SIGWINCH configured with SA_RESTART delays client resize redraws
**File:** `src/main.zig:642-647`
**Severity:** MEDIUM
**Status:** ✅ FIXED

`SIGWINCH` was configured with `SA_RESTART`, preventing blocking system calls from returning `EINTR` on terminal resize signals.

### Root Cause
Setting `SA_RESTART` flag on `SIGWINCH` sigaction setup.

### Fix
Set `flags = 0` on `SIGWINCH` sigaction so blocking I/O calls return `EINTR` immediately on resize.

### Impact
Client display redraws on window resize are delayed until another event occurs.
