# Bug 419 — Region scroll paths leave a stale wrapped=true on the blanked line (#369 follow-up

### 419. Region scroll paths leave a stale wrapped=true on the blanked line (#369 follow-up: erase paths fixed, swap-chain paths not)
**Severity:** LOW
**Status:** 🔴 OPEN

#369 fixed the erase paths, but the scroll paths move existing `GridLine` **structs** by swap-chain/`shiftDown`, so the blanked line inherits the incoming struct's `wrapped` flag: `scrollUpInRegion` bubbles the top region row down into `bottom`, then memsets it but never resets `wrapped` (:585-589); `scrollDownInRegion` mirrors the defect at the region top; whole-screen `scrollDown` and the region SU/SD in the DECSTBM paths share the shape. Compare `advanceLine:626` and `insertLines:1063`/`deleteLines:1091`, which all do `line.wrapped = false` on the cleared row. A blank row flagged as a wrap continuation gets welded into the preceding logical line at the next reflow and lets cursor stepping cross the blank.

**Fix:** set `wrapped = false` after every `@memset(cells, eraseCell())` in these five paths (same rule #369 applied elsewhere).
