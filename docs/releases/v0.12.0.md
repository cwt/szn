# szn v0.12.0

**25 commits** since v0.11.0 (superseding the unpublished `v0.11.1` tag). **1,112 tests** passing on both Zig 0.16.0 and Zig 0.17.1.

---

## Headline: 5-Phase Algorithmic Performance Overhaul, Mouse Drag-to-Resize, 10 ms Escape-Time, and Daemon Lifecycle Fixes (#563–#567)

v0.12.0 delivers a comprehensive, five-phase algorithmic performance overhaul backed by a new dual-toolchain benchmark harness (`zig build bench` and `tools/bench_throughput.sh`), alongside interactive UX improvements and high-severity lifecycle fixes accumulated since v0.11.0. Hot-path quadratic bottlenecks across text reflow, non-blocking I/O queue drains, sixel refcounting, split-border rendering, scroll-region line shifts, and Unicode width lookups have been eliminated — achieving **17× to 40,000× speedups** in targeted microbenchmarks and up to **9.06× faster** end-to-end bulk streaming.

---

## Key Improvements & Features

### 1. Five-Phase Algorithmic Performance Overhaul

- **Phase 0 — Empirical Benchmark Harness (`tools/bench_algo.zig`, `tools/bench_compare.py`, `tools/bench_throughput.sh`)**:
  - Wired `zig build bench` / `zig build bench-build` via `src/bench_exports.zig` with zero runtime or binary-size impact on `szn`.
  - Records median/p95/p99 latency, asymptotic scaling exponents ($\alpha$), allocation counters (`CountingAllocator`), and E2E PTY/IPC throughput across Zig 0.16.0 and 0.17.1.
- **Phase 1 — $O(N)$ Text Reflow & Copy-Mode Fast Paths (`src/grid.zig`, `src/thai.zig`, `src/window.zig`)**:
  - Replaced $\Theta(N^2 / W)$ `word_breaks` and number-length scans in `Grid.rewrap` with monotonic exponential/binary search and a bounded 7-cell forward cap.
  - Tracked Thai/Lao space boundaries incrementally in $O(1)$, skipped Tai-only rules on non-Tai lines, combined `findClusterEnd` + `clusterWidth` into `nextCluster`, and switched `GridLine` capacity reservation to `ensureTotalCapacityPrecise` (eliminating `growCapacity` slack).
  - Added **Tier A** (zero-allocation `forceReflow` no-op when no rows are soft-wrapped) and **Tier B** (OOM-safe existing line buffer transfer), plus scratch-backed span extraction and 2,048-codepoint chunking in `thai.findWordBreaks`.
- **Phase 2 — $O(N)$ Head-Offset `ByteQueue` & `MessageReader` (`src/io.zig`, `src/server/server.zig`, `src/main.zig`, `src/server/pty.zig`, `src/server/message_reader.zig`)**:
  - Replaced quadratic `copyForwards` shifts on partial writes/consumes with `io.ByteQueue` (moving head cursor, amortized $O(1)$ compaction, overflow-free `checkpoint`/`rollback`, and buffer reclamation above 256 KiB) across `DisplayClient.out_buf`, client `out_buf`/`read_buf`, and `Pty.input_buf`.
  - Added a moving head cursor to `MessageReader` so `consume()` is $O(1)$ with zero `memmove`.
  - **Measured gains**: `queue_drain_1k` (8 MiB) **39,020×–40,270× faster** (`32 GiB → 0 B` memmove), `message_reader_drain` **410×–488× faster**, `e2e_sixel_backpressure` server CPU `270 ms → 60 ms` (**4.5× less**).
- **Phase 3 — $O(1)$ Sixel Refcount Guards & Per-Pane Containment Table (`src/screen.zig`, `src/server/render.zig`)**:
  - Added `active_sixel_count` and `has_last_sixel_anchors` on `Screen` (maintained via `setSixelSlot`/`clearSixelSlot`) so `hasSixelImages()`, cell refcount helpers, `shiftSixelAnchors()`, and `renderSixelImages()` Phase 0 run in $O(1)$ when idle.
  - Checked `cell.attr.sixel` first, replaced per-cell loops in `eraseLine(0/1)`, `insertChars`, and `deleteChars` with slice `decrementLineRefs` + `@memset`, added `id % 64` slot probing, and precomputed per-pane sixel containment once per dirty pane in `renderAll`.
  - **Measured gains**: `vt_utf8_stream` **1.61×–4.03× faster**, `vt_csi_k_clear` **23.65×–177× faster**, `render_sixel_grid` (64 sixels) **19.67×–19.86× faster**.
- **Phase 4 — Bounded PTY Drain, `tcgetpgrp` Throttle, & Diff-Guarded Split Borders (`src/window.zig`, `src/server/server.zig`, `src/server/render.zig`)**:
  - Drained non-blocking PTY output up to a 64 KiB / 64-read budget per tick in `Pane.feedPty`, stopping immediately on `EAGAIN`, `pending_sixel` (#204), or EOF (while preserving dirty and sixel hooks on mid-loop `ProcessExited`).
  - Throttled `tcgetpgrp(2)` to 100 ms per window via `Window.last_pgid_check_ms` while keeping 0 ms re-checks on Enter / `SIGCHLD`.
  - Added SIMD-friendly byte-slice row merging for non-sixel/non-copy-mode panes and diff-guarded `drawLayoutBorders` + `border_format` in `Display.renderAll`.
  - **Measured gains**: `render_split_1row` (4 panes) **17.5×–20.0× faster** (`59/60` rows skipped), `e2e_bulk_10mb` **9.06× faster** (`10,347 → 447` frames), `e2e_tcgetpgrp_rate` **8.71× faster**, `e2e_sixel_backpressure` server CPU `270 ms → 40 ms` (**6.75× less**).
- **Phase 5 — $O(H)$ Region Rotation, BMP `charWidth` Table, & $O(W)$ Status Truncation (`src/screen.zig`, `src/char_width.zig`, `src/status.zig`)**:
  - Normalized and `std.mem.rotate`-rotated region rows in $O(H)$ for `Screen.insertLines`, `deleteLines`, and scroll-region `scrollUp`/`scrollDown`.
  - Added `override_min_cp`/`override_max_cp` bounds fast-path, sorted binary-search for disjoint overrides, and a comptime deduplicated 2-level BMP lookup table (~4 KiB rodata) in `char_width`.
  - Replaced repeated `orderedRemove` in `status.buildLine` click-range truncation with $O(W)$ slice truncation.
  - **Measured gains**: `screen_region_scroll` (`H=4000`) **181×–188× faster** (scaling exponent $\alpha$: `2.0 → 1.03`), `char_width_ascii` **26×–27.6× faster**, `char_width_mixed` **12.7×–18.5× faster**.

### 2. Interactive UX & Terminal Emulation
- **Mouse Drag-to-Resize Panes (`src/server/server.zig`, `src/layout.zig`)**: Click and drag within a 2-cell tolerance of interior split borders to resize panes via `Layout.resizePane` when the pane is not capturing mouse events. Gated strictly to interior dividers (`Layout.hasSplitOnAxis`) with `#283` teardown cleanup (#565).
- **10 ms Default `escape-time` (`src/options.zig`)**: Lowered the default `escape-time` from `500 ms` to `10 ms` (matching tmux 3.5), removing noticeable `Esc` lag in Vim/Neovim.
- **Custom Window Title Preservation & `ESC k` Support (Bug #563)**: Preserves OSC 0/2 and screen-style `ESC k <title> ST` application titles across 500 ms auto-rename ticks until the foreground process transitions or emits an empty title.

### 3. Reliability, Daemon Lifecycle & Tooling Fixes (#563–#567)
- **Tier B Reflow Trailing Content Fix (#564)**: Set `gl.cells.items.len = @max(tr.trimmed_len, nw)` in Tier B transfer so shrink reflows never drop trailing characters after interior erased cells.
- **Mouse Border Drag Safety (#565)**: Prevented single-pane and outer-edge drags from shrinking terminals below their layout slot and cleared `mouse_resize_pane`/`mouse_resize_axis` on `destroyPane` and `killSession`.
- **Daemon Startup Resurrection & Leak Fix (#566)**: Parameterized `runServerDaemon(allocator, create_default_session)` and added `waitForInitialSession` so `new-session` / `new` daemons no longer pre-create a phantom `"default"` session — eliminating the 16 ms daemon/shell leak race on rapid `new-session && kill-session`, fixing cold bare `new-session -d` and invalid-args daemon leaks, and guarding clean `ConnectionClosed` EOF logs.
- **Isolated `bench.sh` & Reporting Parity (#567)**: Isolated sockets (`/tmp` `XDG_RUNTIME_DIR`, `tmux -L`), normalized `SHELL=/bin/sh`, built exact `2×5` (10/50 pane) layouts for both multiplexers, and fixed executable-basename classification in `tools/bench_report.py`.

### 4. Packaging & Documentation
- **RPM Packaging (`szn.spec`)**: Removed `ExclusiveArch: %{zig_arches}` from `szn.spec` to broaden Fedora / EPEL build compatibility.
- **Documentation & Repository Updates**: Updated `README.md` with badges, Fedora Copr install instructions, refreshed test/performance metrics, and updated `docs/architecture.md`, `docs/build-run.md`, `docs/concepts.md`, `docs/development/progress.md`, and `docs/development/algorithm-optimization-plan.md`.
