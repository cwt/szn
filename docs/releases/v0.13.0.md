# szn v0.13.0

**15 commits** since v0.12.0. **1,137 tests** passing on both Zig 0.16.0 and Zig 0.17.1.

---

## Headline: OSC 8 Hyperlinks with Click-to-Open, Zig 0.17 Termios Fix, and 12-Bug Audit Sweep (#568–#579)

v0.13.0 introduces full end-to-end **OSC 8 terminal hyperlink** support — from parsing and per-screen storage through delta-safe merged-screen re-emission to bare left-click opening via `xdg-open` — alongside a critical Zig 0.17 termios miscompilation fix and resolution of all 12 defects confirmed during the 2026-11-26 audit sweep (`#568`–`#579`).

---

## Key Features & Improvements

### 1. OSC 8 Hyperlinks & Click-to-Open (`src/hyperlink.zig`, `src/grid.zig`, `src/input.zig`, `src/screen.zig`, `src/server/render.zig`, `src/server/server.zig`)

- **Per-Screen Hyperlink Store (`src/hyperlink.zig`)**:
  - Added `hyperlink.Store` with bounded capacity (`MAX_LINKS = 4096`, `MAX_URI_LEN = 4096`), reusing named IDs (`id=<name>`) with URI updates, assigning fresh IDs to anonymous links, closing links on empty URIs, and preserving URIs that contain semicolons.
  - Expanded `grid.Cell` from `packed struct(u128)` to `packed struct(u160)` with a 1-based `link: u32` index (`0` = unlinked).
  - Preserved active OSC 8 links across SGR resets (`Screen.resetSgrState`), matching the OSC 8 specification.
- **Merged-Screen & Delta-Safe Rendering (`src/server/render.zig`)**:
  - Remapped pane-local hyperlink IDs into the merged screen's `hyperlink.Store` (`remapLink`) so links survive split panes without cross-pane ID collisions.
  - Emitted explicit OSC 8 open/close transitions in `Display.renderContent` and prevented linked cells from being skipped by the unchanged-cell diff cache so outer terminals retain link state across incremental frames.
- **Click-to-Open (`src/server/server.zig`)**:
  - Bare left-clicks on a linked cell in normal mode or copy mode (including scrollback via shared `Screen.rowCells`/`hyperlinkAt` hit-testing) open the URL via `xdg-open` using `fork` + `execvp` (no shell interpolation, non-stdio fds closed, reaped by the server's `SIGCHLD` handler).
  - Drag gestures retain text selection and border drag-to-resize behavior, and panes with mouse mode enabled continue receiving clicks directly.
- **Tests**: Added 14 unit tests covering `hyperlink.Store`, `InputParser`, `Display` rendering/merging, and server click/drag dispatch.

### 2. Zig 0.17 Termios Miscompilation Fix (`src/server/pty.zig`, `src/client/raw.zig`, tests)

- Converted all four `std.c.tcgetattr`/`std.c.tcsetattr` call sites (PTY spawn, client raw mode, and test helpers) to the dual-toolchain `std.posix.tcgetattr`/`std.posix.tcsetattr` API.
- Eliminates a Zig 0.17 miscompilation where `std.c.tcgetattr(fd, &undefined_termios)` followed by `tcsetattr` passed fd `0` to `tcsetattr`, preventing PTY slaves from entering raw mode and hanging DSR tests. Verified across Zig 0.16.0, 0.17.0, and 0.17.1.

### 3. Audit Bug Sweep (`#568`–`#579`)

All 12 confirmed findings from the 2026-11-26 audit validation are resolved with regression tests:

- **Per-Pane Sixel Cell-Size Timeout (`#568`, HIGH)**: Moved `pending_since` from a single server-wide timestamp into each `SixelWaitEntry` so unrelated panes' PTY reads cannot reset or starve another pane's sixel timeout.
- **Preserve Dirty Flags on Render Error (`#569`, MEDIUM)**: Cleared `all_flushed` when `collectPaneBounds` fails in `renderToDisplayClient` so dirty flags remain set for the next render retry instead of dropping frames silently.
- **Pane-Border Cache Invalidation on Rename (`#571`, MEDIUM)**: Invalidated cached pane-border format strings in `Window.setName` and `Session.rename` so manual, OSC-title, and automatic renames update pane borders immediately.
- **Non-Blocking `if-shell` Config Load (`#572`, MEDIUM)**: Removed the 30×1 ms blocking `nanosleep` loop in `applyDirectives`; `if-shell` now polls once with `WNOHANG` and queues still-running children asynchronously via `queuePendingIfShell()` for `tickIfShells`.
- **Monotonic Timeout Clocks (`#575`, MEDIUM)**: Reimplemented `io.currentMillis` on `compat.monotonicNs()` (`CLOCK_MONOTONIC`) instead of wall-clock `gettimeofday`, preventing NTP or manual clock steps from freezing or prematurely expiring timeouts.
- **Border `window_index` Parity (`#570`, LOW)**: Computed `#{window_index}` in `pane-border-format` from `base-index` plus the window's slot in `session.windows`, matching the status line.
- **Config Error & OOM Hardening (`#573`, `#574`, `#579`, LOW)**: Propagated `set-environment` allocation failures instead of silently truncating config load (`#573`); rejected directories (`opendir`) and checked `ferror` in `loadConfigFile` instead of treating them as empty configs (`#574`); preserved the existing `client-log-file` path on allocation failure via dupe-before-free (`#579`).
- **Alt + Multibyte UTF-8 Input (`#576`, LOW)**: Routed UTF-8 lead bytes following `ESC` in `InputReader.feedEsc` through the UTF-8 decoder with an `utf8_alt` flag instead of treating the lead byte as Latin-1 and dropping continuation bytes.
- **Test FD Hygiene & Dead Code Cleanup (`#577`, `#578`, LOW)**: Removed double-closed socketpair endpoints in server tests and replaced a hardcoded BSD `O_NONBLOCK` constant with `io.setNonBlocking` (`#577`); removed confirmed dead code in `src/tty/tty_key.zig` and `src/server/socket.zig` (`#578`).

### 4. Packaging & Documentation

- **Copr SRPM Packaging (`.copr/Makefile`)**: Excluded `.cache`, `tmux`, and `*.tar.gz` when creating SRPM source tarballs so local Zig build caches and the upstream `tmux/` reference submodule are omitted (reducing SRPM size from 46 MB to 1.2 MB).
- **Documentation**: Refreshed `README.md`, `docs/build-run.md`, `docs/architecture.md`, `docs/concepts.md`, `docs/development/progress.md`, and `docs/log.md` to reflect OSC 8 hyperlinks, `Cell` (`u160`), `1,137` passing tests, refreshed Linux benchmark metrics, and the Zig 0.17 `std.posix` termios portability guidance.
