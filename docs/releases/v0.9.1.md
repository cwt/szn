# szn v0.9.1

**2 commits** since v0.9.0. **967 tests** passing.

---

## Headline: Hotfix for Window Status Option Routing & Real-Time Status Invalidation

v0.9.1 is a targeted hotfix release addressing configuration routing, status-line cache freezing, and character alignment issues affecting `window-status-format` and `window-status-current-format` (Bug #440).

---

## Key Improvements & Bug Fixes

### 1. Global Window Option Routing & Fallback (#440)

- **Unscoped `set -g` Fallback**: When configuring options with `set -g` (or bare `set`) in config files or via CLI without explicit `-s` / `-w` flags, option resolution tries session options first; on `error.UnknownOption`, it seamlessly falls back to window options. Directives such as `set -g window-status-format '#I:#W'` and `set -g window-status-current-format '#I:#W#F'` now configure correctly instead of being dropped.
- **Dedicated `set-window-option` / `setw` Command**: Added native support for `set-window-option` / `setw` in both `szn.conf` configuration files and the interactive CLI command table (bringing total available commands to 49).

### 2. Status Cache Invalidation on Window Switching (#440)

- **Real-Time Status Bar Update**: Fixed an issue where `renderToDisplayClient()`'s status cache froze the rendered status line across window switches within the same second. Active window switches (`next-window`, `prev-window`, `select-window`, `last-window`, and mouse status-bar tab clicks), window lifecycle operations (`new-window`, `kill-window`, `rename-window`), and status option changes now mark `server.status_dirty = true` to force an immediate status-line redraw.

### 3. Single-Quote Comment & Format String Handling (#440)

- **Single Quotes in Config Files**: Updated `stripInlineComment()` and `parseValue()` in `src/cfg.zig` to support single-quoted format strings (`'#I:#W'`). Embedded `#` characters inside single quotes are no longer misinterpreted as inline comment delimiters.

### 4. Per-Window Status Format Overrides (#440)

- **Per-Window Format Evaluation**: Status line rendering now extracts format options (`window-status-format`, `window-status-current-format`) per individual window instead of applying the active window's format globally to all windows.

### 5. Wide Character Cell Width Truncation (#440)

- **Cell-Width Aware Truncation**: Fixed `truncateVisible()` in `src/status.zig` to measure character cell width via `char_width.charWidth()`, matching `visibleLen()` and preventing half-cell splits or column desync when displaying wide CJK characters and emojis in the status bar.
